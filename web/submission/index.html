01 / BUILT TOWARD STELLAR

Understand the proof.
Then check the context.

For Soroban developers, reviewers, and the people using their applications. A focused path from local verification to useful transaction diagnostics.

  1. 01IMPLEMENTED LOCALLY

    Recognize & verify

    Recognition of 16 Stellar Private Payments testnet keys, supported RISC Zero receipt verification, and an UltraHonk format compatible with a referenced Soroban verifier.

    Key recognition is not end-to-end payment validation. No valid Private Payments proof tested yet.

  2. 02PROPOSED NEXT

    Connect the transaction

    Inspect a supported Stellar transaction, extract available proof data, and separate local verification from the network outcome reported by an RPC provider.

    Stellar transaction lookup is not implemented.

  3. 03PROPOSED NEXT

    Explain the boundaries

    Add reviewed circuit explanations and application-specific checks for accepted roots and spent nullifiers, followed by preflight diagnostics.

    Simulation is not settlement. State can change.

What works today

Local proof checks, artifact identification, readable reports, and evidence export and rerun. Supported formats vary by interface. Developed as ZK-Proofscan under GPL-3.0-or-later.

What is still ahead

Qualified explanation review, independent security review, a complete Stellar application integration, and external developer pilots. Prototype only; unaudited and not a production release.
