      Repeat someone else's check

      Proof files are checked locally and are not uploaded. A transaction lookup sends the transaction hash and standard RPC requests to the provider named above. Stellar lookups may also request ledger entries and provider health. Inspecting an unsigned transaction happens on this device and sends nothing. Providers can see requests and ordinary connection information. Public proof inputs can identify or link people, so think before sharing a result or export.
