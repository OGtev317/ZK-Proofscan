      Repeat someone else's check

      Proof files are checked locally and are not uploaded. A transaction lookup sends the transaction hash and standard RPC requests to the provider named above. Stellar lookups may also request the ledger entries needed to read the called contract and verifier. The provider can see the request and ordinary connection information. Public proof inputs can identify or link people, so think before sharing a result or export.
