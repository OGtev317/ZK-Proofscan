# OtakuCoin

Working name for a proposed protocol and SDK for **physical-encounter proofs**:
signed records that two devices exchanged data over a short-range channel,
which applications can build on for trust, offline data sharing and later
settlement.

**Status: project charter only.** There is no code, specification, token,
contract or hosted service yet. Read [the charter](docs/PROJECT_CHARTER.md) and
[the handoff](docs/HANDOFF.md).
